仅设计演示

设计说明

v3 相对 v2 的目标：少一点控件，多一点确定感。

一条路径

上面是你说的或写的，下面是将写入的内容。说话和打字用同一块输入区，不再有“听写 / 文字 / 转录”三个模式。

一个输出开关

右上角一个胶囊：整理、翻译或原话。v2 的“翻译开关 + 方向 + 三个输出页签”合并为一个。

需要时才出现

句子操作悬停出现；异常用横幅，不用弹窗；失败给出口，不静默降级。

回车即写入

处理中按回车会排队，完成后自动写入；任何编辑、失败或 Esc 都会取消排队。

边界与未验证

  • 整理在演示语料外保持原文；翻译只覆盖预设语料，其余明确提示“原型未接入模型”。
  • 保真检查只能提示风险，不能证明语义正确；原话始终可见、可回退。
  • OS 全局热键、跨应用光标捕获与回填、Windows 实机、M2/16 GB 联合调度均未验证。
  • “更好的体验”需用真人任务验证：首次完成率、误回填率、修改成本、长口述恢复。
