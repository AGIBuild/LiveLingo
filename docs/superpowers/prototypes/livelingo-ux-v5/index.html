          全局单窗防撕裂

          结构化模式不再逢换行或 800 字硬切拼接，≤2400 字整篇一次推理统合，彻底消除重复标题与上下文割裂。

          协同门禁 + 定向自愈

          双层门禁新增「自我改口数字豁免」与「防越界写代码 / 防角色套话拦截」，失败时带具体原因单次同模式自愈，不静默退回散文。

          宿主感知 + 零损切换

          Cursor 默认落位 AI 任务指令、Linear 落位待办、飞书文档落位汇报；原话常驻，5 种模式可随时无损来回切换对比。

          以润色质量为第一目标：五层工程改造对照

          质量维度传统单提示词润色（旧方案）质量优先多场景润色（v5 定稿）
          口语思维撤回与倒叙按原话顺序顺句，保留被推翻线索，核心诉求仍埋在段尾目标倒装归位 + 废案彻底剪枝（如剔除被改口的“重试 3 次”，只留生效的 401 与 30 秒）
          长短输入格式适配无论长短硬套 4 个 Markdown 标题，脑补“你是一位资深专家”等废话自适应颗粒度：≤2 句短纠偏紧凑直出；复杂委派按实际要素输出目标 / 上下文 / 硬性约束，缺项绝不硬凑

          内置 5 种正交场景规格

          展开查看 5 种内置模式与 3 个扩展模板的质量红线
          • AI 任务指令（⌘1 · AI 结对核心）：面向 Cursor / Claude Code / Copilot / ChatGPT。倒叙目标置顶、正负护栏分离、短纠偏免套壳、严禁模型替用户回答或偷写业务代码。
          • 口语顺句（⌘2 · 即时沟通）：面向微信 / Slack / 飞书消息。接碎句、去口头语与改口残片，保留真人说话口吻，零标题列表。
          • 得体书面（⌘3 · 邮件与评审）：面向正式邮件、PR Review 与客户沟通。克制专业的书面段落，显式封杀“赋能/抓手/闭环/综上所述”等公文黑话。
          • 待办与派单（⌘4 · 任务拆解）：面向 Linear / Jira / 飞书任务。过滤寒暄与已否决提议，提取动词开头的 - [ ] 清单，绝不编造截止日期或负责人。
          • 汇报与纪要（⌘5 · 决策同步）：面向周报 / 站会 / 评审文档。强制结论先行（BLUF），锁死全部业务指标数值与正反对比。
          • 一键扩展模板：内置 Bug 缺陷与复现、需求规格（Spec/AC）、Commit 说明 三个起步芯片，支持团队自定义沉淀。
