SIMPLE DOES NOT MEAN INCOMPLETE

一份草稿，两条处理路径。

轻浮窗处理短输入；同一浮窗展开为长文工作台，不另造一套会话核心。

01 / 不改变习惯

唤起 → 输入 → 回填

保留已有全局唤起机制和配置。捕获原输入目标；审阅后用指定键回填。不是自动发送，不“猜”新的输入框。

02 / 输出目标明确

看原文，不等于改输出。

回填版本有显式选择器。开启翻译即选择译文，录音期间也能看译文；原文对照只展开，不切换回填语言。

03 / 最少处理链

整理与翻译并行。

流式 ASR 先反馈，二遍原文逐句稳定；整理和翻译分别消费原文。译文对照显示识别原文，不把整理稿冒充翻译来源。

04 / 人始终拥有最后一笔

能编辑，也能改回去。

每句可编辑、可用原文。手动编辑拥有优先权；模型只更新仍属于当前版本的结果。前文改动会使依赖结果失效，不覆盖人工稿。

05 / 异常不是死路

失败保留证据与出口。

处理未完成不写入半截译文；明确显示失败，可编辑、重新请求或改用原文。目标失效时由用户重新绑定，不向新前台应用自动注入。

06 / 输入法与无障碍

快捷，但不抢按键。

中文候选确认优先。Tab 保留焦点导航，Shift+Enter 换行，按钮都有文本或可读名称。减少动画、深色和窄视口均有设计。

为什么不是其他布局？

始终双栏：适合长文对照，但短听写占屏过多。全部放进胶囊：漂亮，但长录音难审阅。推荐轻浮窗 + 展开工作台：高频输入短路径，复杂任务按需展开。

没有自动写入、自动发送或强制双击热键。保真检查无法保证语义完全正确；术语和格式检查亦不能替代人工审阅。
