设置页体验与布局重构说明（v6）

从「高密度平铺清单」演进为「意图分层、卡片分组、渐进披露、零点击可扫视」的现代桌面应用设置体验。

1. 从 4 栏塞满 → 3 组 6 域

将原先高达 2500px 的「语音与翻译」拆解为听写与翻译 / 润色场景 / 词库与纠错三个意图清晰的独立域，侧边栏带分组标题、图标、实时状态与 ⌘K 搜索。

2. 卡片分组替代平铺分割线

引入画布底色 + 浮起卡片的双层表面层级；每个卡片有明确分组小标题，把相关控件聚成 2–4 项一组的「视觉块」，扫一眼就知道这一块管什么。

3. 可视化直选替代黑盒下拉

对 2–3 项的互斥设置（外观、回填键、默认输出形态、翻译方向、界面语言）改用分段单选或可视化卡片直选，零点击即可对比全部选项。

4. 模型页按「阶段 × 来源」解耦

顶部硬件与隐私精简为双区总览条；三段流水线 Tab 直观显示当前生效模型与来源；阶段内部用「本机离线 / 本机宿主 / 云端服务」分段切换，彻底消除三层大平铺。
